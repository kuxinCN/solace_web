# 背景音乐功能说明

本文档说明音乐功能的设计、网易云官方播放器的用法、能力边界，以及运维注意事项。
改这块代码前请先读一遍，尤其是「能力边界」那一节 —— 有几件事**不是我们没做，是浏览器/官方限制**。

---

## 一、三种音源

后台「背景音乐」→「歌单管理」里可以添加三类内容，用 `source` 字段区分：

| source | 来源 | 说明 |
|---|---|---|
| `local` | **本地上传** | 文件存在服务器 `public/music/`，Nginx 直接 serve。功能最完整 |
| `url` | **外链直链** | 指向任意 http(s) 音频地址（你自己的 CDN 等） |
| `netease` | **网易云** | 只存内容 ID，用户端用**官方外链播放器**嵌入 |

### 后台可以随时切换音源

设置项 `music.source`：

- `local` → 播放 `local` + `url` 的歌，**支持自动播放、切歌、音量**
- `netease` → 展示 `netease` 的歌，用官方 iframe 播放器

**两种歌单可以同时维护**，切过去立刻生效，不用改数据。

## 二、网易云官方播放器

### 这是唯一合规的嵌入方式

网传的 `music.163.com/song/media/outer/url?id=xxx` 之类「直链」**不是官方接口**，随时失效且违反服务条款。
本项目**不做任何地址解析**，只用官方提供的外链播放器。

### 地址格式

```
https://music.163.com/outchain/player?type=<类型>&id=<内容ID>&auto=0&height=<高度>
```

### 参数表

| 参数 | 必填 | 取值 | 说明 |
|---|---|---|---|
| `type` | ✅ | `2` / `0` | **`2` = 单曲**；**`0` = 歌单** |
| `id` | ✅ | 数字 | 歌曲 ID 或歌单 ID |
| `auto` | ✅ | `0` | **必须填 0**。填 1 会自动播放，多个播放器会一起响 |
| `height` | | 数字 | 单曲用 `66`；歌单要显示列表，用 `430` |

### 怎么拿 ID

| 场景 | 操作 |
|---|---|
| 电脑网页 | 打开歌曲/歌单页，地址栏 `music.163.com/#/song?id=1901371647` → `id=` 后面那串数字 |
| 手机 App | 分享 → 复制链接 → 链接里能找到 `id=数字` |
| 歌曲分享链接 | 形如 `https://music.163.com/song?id=1901371647` |

后台**两种都收**：直接填数字，或者粘贴含 `id=` 的完整链接（会自动提取）。

## 三、能力边界（很重要，别误以为是 bug）

### ✅ 用户能做的

- **可以直接点播放器里的按钮**：播放 / 暂停 / **上一首 / 下一首**
- **歌单播放器（`type=0`）里点列表可以切换歌曲**
- 调音量（部分浏览器上播放器自带）

这些是官方播放器**自带的能力**，用户点 iframe 里面就行。

### ❌ 我们（代码）做不到的

| 做不到 | 原因 |
|---|---|
| 用我们的按钮控制它 | **跨域**：iframe 里的 DOM 拿不到，也调不了它的播放状态 |
| 把网易云的歌混进"自动播放"队列 | 同上，且官方播放器不接受外部指令 |
| 读它的播放状态（知道它正在播，去暂停本地音乐） | 跨域 |
| 改它的外观样式 | 跨域 |
| **服务器端取播放地址** | **官方没有开放这个接口**，做了就违反服务条款 |

**一句话**：网易云的歌，**控制权在官方播放器手里，用户点它就行**；我们只能把它摆在那儿。

### ⚠️ 还需要注意

- 用户网络**必须能访问 `music.163.com`**，否则播放器是空白的 → 见下一节的自动降级
- 首次进入时播放器可能需要**用户点一下**才会加载出内容

## 四、自动降级（`music.autoFallback`）

**问题**：如果用户网络访问不了网易云，浮窗里会是一片空白，看起来像坏了。

**做法**：音源选「网易云收藏」时，前端会先**探测能否访问 `music.163.com`**：

```js
// 用 no-cors 探一下就通不通（读不到内容，但能判断网络是否可达），超时 4 秒
fetch("https://music.163.com/favicon.ico", { mode: "no-cors", cache: "no-store", signal })
```

- **能访问** → 正常显示网易云播放器
- **访问不了 / 超时** → **自动切回本地歌单**，并在浮窗标题栏显示「已降级为本地」

**可在后台关掉**：设置项 `music.autoFallback`，关掉后无论能不能访问都固定显示网易云播放器。

## 五、后台操作步骤

### 添加本地上传的歌

1. 后台 →「背景音乐」→ 歌单管理
2. 可选：填歌名 / 歌手（留空则用文件名）
3. 点「选择文件」→ 选一个 `mp3 / m4a / wav / ogg`（≤ 20MB）
4. 上传后列表里出现，状态"启用中"

> 上传会自动校验**文件头魔数**，改扩展名骗不过去。

### 添加外链直链

1. 点「外链直链」标签
2. 填音频完整地址（`https://` 开头）
3. 点「添加」

### 添加网易云

1. 点「网易云收藏」标签
2. 填**歌曲 ID**（或含 `id=` 的链接）；如果是**歌单**，还要把「内容类型」选成 **歌单（type=0）**
3. 点「添加」

### 排序 / 启停 / 删除

列表每行右侧：`↑` `↓` 调顺序，`停用` 暂时隐藏，`删除` 永久删除（**本地上传的会连带删磁盘文件**）。

## 六、备份与迁移

**⚠️ 音频文件在磁盘上，不在数据库里** —— 数据库备份**不包含音乐**。

所以有两个备份途径：

**① 每日自动备份**（`scripts/backup-db.sh` 已包含）

```bash
bash scripts/backup-db.sh
# 输出里会多一行：音乐目录已备份，大小 xxx
# 产物：backups/music-日期时间.tar.gz
```

**② 后台手动导出音乐包**

后台 →「背景音乐」→「**导出音乐包**」→ 下载一个 JSON（歌单元数据 + 全部音频的 base64）。

换服务器时：「**导入音乐包**」选那个 JSON 即可恢复。

- 默认**合并**模式：同名文件跳过、按"标题+歌手"去重
- 加 `?mode=replace` 可清空后全量导入（换服务器时用）

> 为什么用 JSON 而不是 zip：纯 Node 没有内置 zip 能力，引第三方库又多一个依赖。
> JSON + base64 体积大 33%，但零依赖、跨平台、导入解析也简单。这个接口是给备份/迁移用的，不是日常下载。

## 七、常见问题

**Q：为什么音乐不是页面一加载就播？**
A：**所有现代浏览器都禁止**自动播放（防广告骚扰），任何网站都一样。我们的做法是：监听用户**第一次点击/触摸/按键**，之后再开始播，体感接近"进站就放"。如果上次访问开过音乐，这次点任意位置会自动接上。

**Q：网易云的歌为什么不能自动播放？**
A：跨域。iframe 里的播放控制权在网易云手里，我们发不了指令。用户点播放器上的按钮就行。

**Q：能不能把网易云歌曲的直链抓出来自己播？**
A：不能，也不做。官方没开放这个接口，抓取违反服务条款且随时失效。

**Q：音频为什么不存数据库？**
A：会踩三个坑：① MySQL 5.7 的 `max_allowed_packet` 默认 4MB，5MB 的歌插不进去；② 你的连接池只有 5 个连接，一个人播放就占满一个，三个人同时听歌会让聊天/日记排队；③ 每次播放都从库读几 MB BLOB，比 Nginx 发磁盘文件慢一个数量级。

**Q：上传失败提示"写文件失败"？**
A：检查 `public/music/` 目录权限：

```bash
mkdir -p /www/wwwroot/solace/public/music
chmod 755 /www/wwwroot/solace/public/music
```

**Q：用户端浮窗不显示？**
A：按顺序排查：① 后台「启用背景音乐」是否打开；② 歌单里是否有**启用中**的歌；③ 后台和安装页本来就不显示（设计如此）；④ 音源选的是网易云但一首都没加。
